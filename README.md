# 🎹 Piano MIDI Synthesizer & Player
Welcome to the official release of **Piano** — a lightweight, standalone virtual piano and audio synthesizer for Windows.
          
## 🚀 Features in this release:
* **International Support:** Multi-language interface with 14 languages selectable on-the-fly (including custom GDI+ vector flags).
* **Classic Masterpieces Built-in:** Includes 18 iconic melodies (Shostakovich, Mozart, Bach, Rybnikov's "Munchhausen", Legrand's "The Umbrellas of Cherbourg", and more).
          
## 🎮 How to control:
* Use the **LEFT mouse button** to switch vector flags and browse melodies.
* The big PLAY NOTE button can be triggered by either clicking your LEFT mouse button or pressing the SPACE bar.
